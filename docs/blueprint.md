# **App Name**: EngineerHub Portfolio

## Core Features:

- Dynamic Content Presentation: Securely manage and display personalized 'About Me', 'Skills & Tech Stack', 'Experience Timeline', and 'Certifications' content via a content management interface, viewable by visitors.
- Interactive Project Portfolio: Showcase featured data engineering projects and case studies with robust filtering options by technologies and categories, leading to detailed views. Data will be fetched from Firestore.
- Resume & Document Hosting: Enable visitors to view and download the professional resume and detailed case studies (PDF format) directly from the site. Links to these documents will be stored in Firestore.
- GitHub Activity Integration: Display a live feed of recent GitHub activity and highlight key repositories or contribution statistics.
- AI-Powered Skill Matcher: An interactive tool for recruiters to input a job description, receiving an AI-generated highlight of the most relevant skills and projects from the portfolio.
- Admin Content Management System: A private, secure interface for the Data Engineer to update all dynamic portfolio content, including project details, skills, experience, and document links, powered by Firestore.
- Adaptive Theme Switching: Implement a toggle for users to switch between a sophisticated dark mode and a clean light mode, enhancing user experience based on preference.

## Style Guidelines:

- Dark Color Scheme. Primary accent: Deep Azure (#2C528D) evoking professionalism and digital expertise. This hue of blue balances innovation with stability, chosen for a tech-focused, professional appeal in a dark environment.
- Background color: Near-black with a subtle cool undertone (#1A1C21), providing a sleek, modern canvas that enhances readability of content and allows interactive elements to pop.
- Accent color: Vibrant Teal (#4FD0D9) for highlights and interactive elements, analogous to the primary while providing strong contrast for call-to-actions without being overpowering.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, slightly technical yet approachable feel. Body font: 'Inter' (sans-serif) for high readability across devices and a clean, professional aesthetic.
- Crisp, minimalist SVG icons with geometric forms. Utilize outline or duotone styles to maintain a modern and professional aesthetic that aligns with a data engineering brand.
- Employ a responsive grid-based layout with ample negative space to emphasize content clarity and breathability. Use consistent spacing units to ensure visual harmony and a premium feel across all breakpoints.
- Subtle, deliberate animations for interactive elements like hover states on cards and buttons, and smooth page transitions using fades or slides to create a polished and engaging user experience without distractions.
